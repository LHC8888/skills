# 单元测试风险轴

用法：先按改动性质挑风险轴，再按“最小必测集”生成任务。只展开命中本次新行为/新风险的轴。

## 风险轴清单（可执行版）


| 轴           | 何时触发                    | 最小必测集                     | 常见误测             | 可跳过条件                |
| ----------- | ----------------------- | ------------------------- | ---------------- | -------------------- |
| **边界值**     | 数值/字符串/数组输入             | `min`、`max`、空值、越界各 1 条    | 只测 happy path    | 仅改注释/类型别名            |
| **类型转换**    | `unknown`/反序列化/跨层输入     | 合法类型 + 非法类型 + 混合类型        | 只信 TS 编译期        | 输入已被上游 schema 强校验且未改 |
| **纯度**      | 声称纯函数                   | 同输入同输出；不修改入参/全局           | 断言内部实现           | 明确是副作用函数             |
| **异步顺序**    | Promise/定时器/并发          | resolve、reject、超时/取消各 1 条 | 不测竞态与取消          | 完全同步逻辑               |
| **错误传播**    | try/catch/Result/throw  | 错误路径是否向上游暴露可处理信息          | 吞错后仍判 pass       | 确认无错误分支且未改           |
| **副作用**     | IO/DB/API/cache         | 副作用发生 + 幂等性/重复调用行为        | 只验调用次数不验结果       | 本次无外部状态写入            |
| **mock 边界** | 依赖外部组件/服务               | 给出“mock/不 mock”理由并验证行为    | mock 过量导致只测 mock | 可使用稳定测试环境替代          |
| **契约一致性**   | tRPC/service DTO/Zod 输出 | 请求/响应 shape 与错误码至少各 1 条   | 只验字段存在，不验语义      | 契约层未涉及               |


## 路由建议

- 纯函数/工具库：优先 `边界值 + 类型转换 + 纯度 + 错误传播`
- hook/副作用函数：优先 `异步顺序 + 副作用 + mock 边界`
- service/tRPC：优先 `契约一致性 + 错误传播 + 副作用`
- 状态机/复杂流程：优先 `异步顺序 + 错误传播 + 合法/非法转移`

## 用例展开方法速查（按输入类型自动套用）

碰到对应输入类型必须**用方法系统展开**，不要凭感觉只写 1-2 条：


| 输入类型              | 应用方法           | 自动展开                                                     |
| ----------------- | -------------- | -------------------------------------------------------- |
| 数值字段              | BVA 边界值分析      | `0 / 1 / -1 / MIN / MAX / MAX+1 / NaN / null / undefined` |
| 字符串字段             | 等价类 + BVA      | 空 / 单字符 / 极长 / 特殊字符 / unicode emoji / 仅空白 / null         |
| 数组 / 集合           | BVA            | 空 / 单元素 / 满 / 超长 / 含 null / 含重复                          |
| 多布尔条件             | 决策表            | 2^N 组合（N≤4 全展开；N>4 用 pairwise）                           |
| 状态机               | 状态转换覆盖         | 所有合法转移 + 至少 1 条非法转移 + 1 条循环                              |
| 枚举 union type     | 等价类            | 每个值 1 条 + 1 条非法值                                         |
| Date / 时间         | BVA + 边界       | epoch / now / 极远未来 / 极远过去 / 跨时区 / DST 切换                 |
| 对象 / Schema       | 字段缺失 + 多余字段    | 必填缺失各 1 条 / 类型错 / 多余字段透传 / 嵌套 null                       |

> 错误推测：开发容易猜不到的输入也要列——unicode 零宽字符、emoji、SQL 注入字符、超长输入、并发同 ID 提交。

## 任务样例（本文件专属）

```text
[风险轴] 边界值-配额下限
前置条件：quota=0
步骤：调用 canSubmit(quota)
期望：返回 false（可观察行为）
优先级：P0
执行：Vitest
```

```text
[风险轴] 契约一致性-createTask procedure
前置条件：合法入参与非法入参各一组
步骤：直接调用 procedure
期望：成功时返回 {id,status}；失败时返回可识别错误码
优先级：P0
执行：Vitest + mock ctx
```
