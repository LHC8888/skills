# 浏览器风险轴

> 用法：先扫一遍这 6 条，决定本次需要生成哪些维度的用例。**不是每条都要生成**：只在本次新行为 / 新风险（SKILL.md §1.5 起步四问第 3 问 — 本次边界）命中维度时才展开。

## 6 条主轴


| 轴            | 何时触发                                     | 用例方向                                                                       |
| ------------ | ---------------------------------------- | -------------------------------------------------------------------------- |
| **输入**       | 涉及文本字段、上传、可粘贴区域                          | 空 / 极长 / 特殊字符 / unicode emoji / 复制粘贴 / 浏览器 autofill / 多余空白                 |
| **状态**       | 涉及账号态、权限、配额（按需展开矩阵 ↓）                    | 未登录 / 免费 / 试用 / 付费 / 过期 / 封禁 / 新注册                                         |
| **环境（含兼容性）** | 涉及响应式 / i18n / SSR-CSR / 浏览器差异（按需展开矩阵 ↓） | 视口 / locale / 时区 / 网络 / feature flag / 浏览器内核 / DPR / safe-area / 扩展 / 隐私模式 |
| **时间**       | 涉及异步、持久化、长操作                             | 慢网（Slow 3G）/ 离开 tab 后回来 / 刷新中操作 / 长时间空闲 / 服务端响应延迟                          |
| **并发**       | 涉及 mutation、提交、跳转                        | 双击 / 快速重复点击 / 多 tab 同时操作 / 提交中再点击                                          |
| **故障**       | 涉及网络请求、外部依赖                              | 接口失败 5xx / 业务错 422 / 超时 / 中途取消 / 离线                                        |


## 用例展开方法速查（按改动类型自动套用）

碰到对应改动类型必须用方法系统展开，**不要凭感觉只测 happy path**：


| 改动类型       | 应用方法        | 自动展开维度                                                                |
| ---------- | ----------- | --------------------------------------------------------------------- |
| 表单         | 等价类 + BVA   | 必填空 / 极长 / 特殊字符 / unicode emoji / 复制粘贴 / autofill / 重复提交防护 / 离开未保存提示 |
| 列表 / 数据加载  | 状态覆盖        | empty / loading / error / success / 分页边界 / 切换筛选清旧数据 / 刷新一致 / 滚动恢复     |
| 多步流程 / 状态机 | 状态转换覆盖      | 主路径 + 中断恢复 + 回退后重提 + 重复提交防护 + 并发同 ID                                  |
| 多账号路径      | 决策表（账号态正交）  | 未登录 / 免费 / 试用 / 付费 / 过期 / 封禁 各跑一次（按可见性挑相关项，详见下方状态轴矩阵）                 |
| 视觉 / 还原度   | 多视口 + 主题正交  | 375 / 768 / 1280 × 暗色 × locale，必查项见 `ui-fidelity.md`                  |
| 路由 / 跳转    | 边界 + 错误推测   | 直接 URL / 刷新 / 后退 / 鉴权失败重定向 + 回跳 / 404 fallback / 客户端导航 vs SSR 一致      |
| 弹窗 / Modal | 状态转换 + 错误推测 | 触发 / 关闭（ESC / 遮罩 / X / 取消）/ 嵌套层级 / 焦点归位 / body 滚动锁                    |
| 异步 / 慢网    | 时间轴         | 慢网（Slow 3G）/ 中途离开 / 中途刷新 / 长时间空闲 / 服务端响应延迟                            |


> 错误推测：开发猜不到的输入也要列——unicode 零宽字符、emoji、SQL 注入字符、超长输入、并发同 ID、双击防抖。

## 环境轴展开矩阵（仅在涉及响应式 / i18n / SSR / 浏览器差异时打开）


| 维度                  | 何时必生成                                                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| 视口                  | 改了样式 / 布局 → 至少 375、768、1280 各生成一条                                                                              |
| locale              | 改了文案 / 数字 / 日期格式 → 至少切一种非英语 locale                                                                             |
| 时区                  | 涉及时间显示 / 倒计时 → 切到非 UTC+8 验一次                                                                                   |
| 网络速度                | 涉及加载态 / 重试逻辑 → 标注 DevTools Slow 3G                                                                             |
| feature flag        | 改动在 flag 后面 → 开 / 关两侧都生成                                                                                       |
| **浏览器内核**           | 改了关键交互、CSS 不常见特性 → 至少 Chromium + Safari 各跑一次（Safari 对 `position: sticky` / `100vh` / `dvh` / Date 解析等 quirk 多） |
| **DPR / 高分屏**       | 改了 1px border / 像素稿图片 → 验 retina 下不模糊、不缩放                                                                      |
| **safe-area / 刘海屏** | 移动端布局 → 验 iPhone 14 Pro 等 safe-area 顶部 / 底部不被遮                                                                 |
| **浏览器扩展**           | 改了表单 / 输入 → 验密码管理器 autofill 不破坏布局；广告拦截器不删错节点                                                                   |
| **隐私模式**            | 改了 storage / cookie / 第三方追踪                                                                                    |
