# 浏览器场景表（已知坑库）

> **本节是"已知坑库"，不是"通用清单"，更不是"必填清单"。通用项已抽到 risk-axes.md 风险轴和 SKILL.md §2 Must Rules（§2.1 字段 / §2.3 执行规则）里，本表只列该场景特有的用例点**。
>
> **关键约束**：场景表只覆盖本次新行为（SKILL.md §1.5 起步四问第 3 问 — 本次边界）所属场景的特异坑。如果新功能复用了项目已有的稳定 `<FormField>` / `<Button>` / `<ToolPage>` 等模板或组件，**模板/组件层面的通用项默认跳过**——它们的稳定性已被项目里 N 个其他实例验证过 N 次（与 SKILL.md §2.3「模板复用默认不重测模板稳定项」一致）。
>
> 用法：先按本次边界 + 风险轴生成本次专属用例，再来本节查该场景特有的额外坑，**叠加生成**而不是 OR。

## 1. 弹窗 / Modal / Dialog

- 打开后初始焦点进入弹窗、关闭后焦点归位到入口元素
- 关闭路径全跑：关闭按钮、ESC、点遮罩、点取消
- body 滚动锁定（移动端尤其要看）
- 嵌套弹窗（如有）层级与关闭顺序正确
- 内容超长时容器自身滚动，不撑破视口
- 快速重复点击入口不出现重叠 / 错位

## 2. 表单

- 字段渲染、初始值、placeholder 正确
- 必填校验、格式校验、异步校验都触发
- 提交按钮禁用条件：必填未填 / 校验失败 / 必勾选项（条款、协议）未勾选 / 异步校验中；填齐 + 校验通过后立即恢复可点
- 错误提示位置、文案、可访问性（aria-invalid）
- 字段联动（A 变 → B 选项变 / 显隐）
- 重置 / 取消行为
- 离开未保存提示（如适用）
- 浏览器自动填充 / 记住密码不破坏布局

## 3. 列表 / 数据加载

- 四态：loading / empty / error / success 都覆盖到
- SaaS 页面常有 polling / websocket，不用 `networkidle` 当默认稳定条件；用 `domcontentloaded` 后断言列表容器、empty/error/success 元素可见
- 空态文案、空态 CTA（如有）
- 错误态有重试入口
- 分页 / 无限滚动到底行为
- 排序 / 筛选 / 搜索单独验，再组合验
- 切换筛选时上一组数据是否清掉
- 缓存命中：返回页面后是否复用、是否过期刷新
- 滚动位置恢复（详情页返回列表）
- 选中态（多选 / 单选 / 跨页选择）

## 4. 按钮 / CTA

- disable 态：原因可读（tooltip / 文案）
- 跳转目标 / 触发动作正确
- 键盘可达（Tab / Enter / Space）

## 5. Tab / 切换器 / Segmented

- 默认选中正确
- 同 role+name 跨容器冲突时先 scope 容器：例如弹窗里的 `All` tab 用 `page.locator('[role=dialog]').getByRole('tab', { name: 'All' })`
- URL / 历史记录同步策略**按实现而定**：URL 同步设计 → `?tab=xxx` 正确、刷新保持选中、浏览器前进/后退能切 tab；本地状态设计 → 刷新回默认、后退跳出页面而非切 tab
- 切换后子内容懒加载是否正确触发一次
- 切换是否保留状态 vs 重置（与设计一致）

## 6. 路由 / 页面级

- 直接访问 URL 能进入（SSR 或 client redirect）
- 刷新后状态一致(query / 选中项 / 滚动位置)
- 浏览器前进 / 后退路径正确
- 鉴权失败重定向到登录页 + 回跳保留
- 404 / 错误边界 fallback 正确
- SEO meta（title / description / og）正确
- 客户端导航（link） vs 直接访问（SSR）行为一致

## 7. 支付 / 订阅（高风险）

- 多币种切换：金额、税费、支付方式可用性
- 多支付方式：每条通路至少生成一条成功路径用例
- 失败回流：取消、3DS 失败、卡被拒
- 异步状态：webhook 慢到达时 UI 是否正确等待
- 优惠券 / 折扣码：有效、过期、不适用
- 升级 / 降级 / 取消订阅
- 退款后用户态、配额变化
- 多账号 / 多区域抽样（按需）
- 服务端 log 重点看：支付服务、webhook 入口、订阅状态机

## 8. 登录 / 鉴权（高风险）

- 登录、登出、注册全跑
- 第三方登录（Google / Apple / etc.）回跳
- 错误密码 / 不存在的账号 / 频率限制
- session 过期：受保护页自动跳登录 + 回跳
- 多端登录策略（如有踢人）
- SSR 与 CSR 鉴权一致（不要 SSR 已登录但前端显示未登录）
- 记住登录态、跨刷新保持

## 9. 国际化 / 主题

- 切语言后所有文案变化（不要漏 key）
- 长文本不撑破容器、不溢出截断异常
- 数字、日期、货币按 locale 格式化
- RTL（如果支持）布局对称
- 暗色模式覆盖：背景、文字、边框、阴影、图标
- 切换主题不闪屏（FOUC）

## 10. 图片 / 媒体

- 占位图 / skeleton 期间无跳动（CLS）
- 加载失败兜底图
- 懒加载首屏可见、滚动后加载
- alt / aria-label 有意义
- 视频自动播放策略、声音默认静音
- 大图压缩 / responsive srcset

## 11. a11y 基础位（轻量）

> 本节只覆盖最关键的可访问性基础位。深度 a11y（屏幕阅读器朗读、ARIA live region、键盘陷阱、焦点循环）单独立 issue 处理，不在本 skill 范围。

涉及交互组件 / 表单 / 公开页时必查：

- 颜色对比度（暗色模式同样要看）—— WCAG AA 4.5:1 文字、3:1 大字
- 键盘可达：Tab 顺序合理、Enter / Space 触发关键操作、Esc 关弹窗
- focus-visible 焦点可见，不被自定义样式覆盖
- 表单 label 关联（`<label for>` 或 `aria-labelledby`），错误状态加 `aria-invalid`
- 交互元素有可读名（按钮文字 / `aria-label`）

## 12. 性能基础位（按需，深度见 performance.md）

- 首屏无大块 CLS
- 大列表滚动 fps
- 图片 / 字体加载不闪
- 关键页 Lighthouse 分数不退化
