# Bug 报告模板

设计用例时若发现额外 bug（不是本次要修的那个），按下方格式记录为「✗ 已知问题」，随本次用例清单与 evidence 一并输出：

```
[标题] — 一句话描述

环境：[浏览器 / 视口 / 账号态 / locale / 网络]
步骤：
  1. ...
  2. ...
  3. ...
期望：[符合需求或常识的行为]
实际：[出现的错误行为]
频次：必现 / 偶发（N 次中 M 次） / 仅特定状态（注明）
严重性：严重 / 一般 / 轻微
是否阻塞主流程：是 / 否（是则标记“必须修复”）
证据：
  - console: [关键 error 行]
  - network: [失败请求 + payload]
  - 截图: [链接]
影响范围估计：阻断主流程 / 边角问题 / 仅特定账号
```

格式不全的 bug 报告 = 用例清单不完整，不能交付。

## 单元测试场景下的简化版

如果是单元测试场景发现的问题（不是浏览器场景），简化为：

```
[标题] — 一句话描述

测试文件：[file:line]
输入：[具体参数]
期望返回：[值或行为]
实际返回：[值或行为]
是否能在本地复现：是 / 否
是否阻断主路径：是 / 否
严重性：严重 / 一般 / 轻微
```
