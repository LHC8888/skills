# 评估维度库

以下维度按类别组织。根据具体选型目标动态选择，不必全部使用。

## 技术实现

| 维度 | 说明 | 常见适用域 |
|---|---|---|
| 核心原理与架构 | 方案底层机制、关键设计模式 | 通用 |
| 版本与迭代节奏 | 主版本周期、Breaking Change 频率、路线图清晰度 | 通用 |
| 扩展性与插件机制 | 是否支持自定义扩展、插件生态成熟度 | 前端、后端、基础设施 |
| 兼容性 | 浏览器/Node/操作系统/Lang 版本要求，与存量系统集成难度 | 前端、基础设施 |

## 性能与资源

| 维度 | 说明 | 常见适用域 |
|---|---|---|
| 基准数据 | QPS/TPS、P99 延迟、内存占用、CPU 占用、冷启动时间 | 后端、基础设施、前端运行时 |
| 包体积 / 镜像大小 | Bundle size、依赖树体积、Docker 镜像分层 | 前端、移动端、基础设施 |
| 并发模型 | 线程/进程/协程/Goroutine/EventLoop 模型及上限 | 后端、基础设施 |
| 缓存策略 | 内置缓存机制、命中率、失效策略 | 后端、数据库、CDN |

## 业务契合度

| 维度 | 说明 | 常见适用域 |
|---|---|---|
| 功能覆盖度 | 对业务需求的直接支持程度，是否需要二次开发 | 通用 |
| 场景化匹配 | 具体业务场景（高并发/实时/离线/移动端/大屏）的适配性 | 通用 |
| 数据流/状态管理 | 与业务数据模型的契合度 | 前端、后端 |
| 国际化/本地化 | 多语言、多时区、合规区域支持 | 通用 |
